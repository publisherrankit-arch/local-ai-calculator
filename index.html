Knowledge Base

Frequently Asked Questions About Local AI

Frameworks like Ollama and Llama.cpp will automatically split the layers: as many layers as fit go into your fast GPU VRAM, and the rest overflow into system RAM. While the model will still run, token generation speed usually drops from 40-60 tokens/sec down to 2-6 tokens/sec because system RAM bandwidth (60 GB/s) is 15x slower than GPU VRAM (1,000 GB/s).

Apple uses Unified Memory Architecture (UMA). On a 64GB or 128GB Mac Studio, the GPU can access up to 75%-80% of total system RAM directly. To get 64GB or 128GB of VRAM on a PC, you would need multiple expensive enterprise GPUs (like dual RTX 3090s or an RTX 6000 Ada costing $7,000+).

Quantization compresses 16-bit floating point weights into 4-bit (Q4) or 8-bit (Q8) integers. Q4_K_M reduces the model size by ~70% with less than a 1% loss in reasoning ability, making it the golden standard default for local execution.

The model must store the Key-Value (KV) attention matrices for every token in history across all transformer layers. At 128k context, the KV cache alone can consume 8GB to 14GB of VRAM on top of the model weights!
